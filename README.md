# Osvaldo
Objetivo do Sistema: Automatizar a gestão da oficina mecânica por meio do cadastro simplificado de veículos e emissão de Ordens de Serviço (OS) com
separação de custos de peças e mão de obra. O sistema realiza o cálculo automático com acréscimo de 20% na mão de obra para veículos importados,
restringe opções de pagamento ao modelo à vista (bloqueando fiado/crédito pendente) e apresenta uma interface ultra-simplificada para uso em balcão.
